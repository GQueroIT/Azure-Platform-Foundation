# PowerShell Scripts

Your own weekly automation scripts go here, one per weekend, built from the pattern in
`lessons/07-script-structure-and-first-automation-script.md`.

Naming suggestion: `<verb>-<what-it-does>.ps1`, matching PowerShell's own Verb-Noun convention
(e.g. `Get-VmPowerReport.ps1`, `New-PolicyAssignmentCheck.ps1`).
